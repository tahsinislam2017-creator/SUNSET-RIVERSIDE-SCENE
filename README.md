# Project tittle:
🌅 Sunset Riverside Scene
A 2D animated graphics project built with C++ and OpenGL (GLUT) as part of an academic/personal graphics project. It depicts a peaceful sunset riverside landscape with animated clouds, birds, a boatman rowing, kids playing football, and people walking on a winding road — all accompanied by background music for an immersive experience.

✨ Features
🌇 Multi-layered gradient sunset sky

☀️ Glowing sun with soft alpha-blended halo

☁️ Animated drifting clouds

🐦 Flying birds with flapping wings

🏔️ Layered hills and mountains

🌳 Trees, bushes, and grassy field

⚽ Football match between kids with animated ball movement

🚶 People walking along a curved road

🏠 Small houses near the riverside

🛶 Boatman rowing with animated oar & bobbing boat

🌊 River with ripple animations and sunset reflection

🎵 Looping background music

⌨️ Keyboard controls (pause/resume & reset)

🛠️ Tech Stack
Technology ---------------------------------Purposes
C++ -----------------------Core programming language
OpenGL---------------------Graphics rendering API
GLUT-----------------------Window creation & input handling
WINMM---------------------background music
Code blocks--------------------IDE(.cbp project file included)

🚀 Getting Started
Prerequisites
A C++ compiler (MinGW / GCC / MSVC)
OpenGL + GL
GLUT (freeglut or the original GLUT)
Code::Blocks IDE (recommended)

**Installation & Running
1.Clone the repository
git clone https://github.com/[tahsinislam2017]/Sunset-Riverside-Scene.git
cd Sunset-Riverside-Scene

2.Open in Code::Blocks
Open SunsetRiverside.cbp
Build (F9) and Run (F10)

3.Or compile manually (MinGW on Windows)
g++ main.cpp -o SunsetRiverside.exe -lGL -lGLU -lglut -lwinmm -lgdi32

4.Run
./SunsetRiverside.exe
📝 Make sure backgroundmusic.wav sits next to the .exe file.

**project file structure in your local
[Sunsetriverscene](main folder)--> main.cbp , sunsetriver.cbp , sunsetriver.depend ,sunsetriver.layout , backgroundmusic. 


🎮 Controls
key-----------------------Function
Space---------------------pause animation
R/r ------------------------Reset scene (clouds, birds, boat, ball, road people)
Q/q--------------------------Quit the program
